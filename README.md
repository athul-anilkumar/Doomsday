## Project Description

Doom Date is a web application that takes your birth date and time, and cross-references it with Wikipedia's historical records to find the most devastating tragedy that occurred on the exact day you were born. It calculates your personal "Doom Score" based on the casualties and scale of the disaster, synchronizing your existence with cosmic misfortune.

### The Problem (that doesn't exist)
People are far too happy on their birthdays. They celebrate life, eat cake, and feel special, completely ignoring the fact that the universe is a chaotic void of endless suffering. There's an acute lack of existential dread during birthday parties.

### The Solution (that nobody asked for)
We bring the dread back to your birthday by showing you exactly what horrific event the universe was distracted by when you were born. Complete with a creepy VHS-style camcorder interface, ominous background music, and a live timer counting the days since your synchronized tragedy!

## Technical Details

### Technologies/Components Used

* HTML & CSS (Vanilla, with VT323 font for retro vibes)
* JavaScript (Vanilla frontend)
* Node.js & Express.js (Backend server)
* Wikipedia REST API (Data source for historical events)


Installation
1.	Open your terminal or command prompt and navigate to the directory containing your project files.
2.	Install the required dependencies (such as Express, CORS, and dotenv) by running the following command: 
npm install

1.	Once the installation is complete, start the backend server by running:
node server.js
2.	The terminal should display a message confirming the server is active: Doom server active on http://localhost:3000 
3.	Open your web browser and go to http://localhost:3000 to view and interact with the application.
